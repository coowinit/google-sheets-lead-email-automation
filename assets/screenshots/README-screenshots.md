## 截图维护建议

- 公开仓库前，应对真实邮箱、电话、地址和客户姓名进行打码；
- 替换截图时保持文件名不变，README 中的图片链接即可继续使用；
- 截图应尽量保留关键菜单、函数名称、字段名和日志结果；
- 不要在截图中暴露不必要的账号信息或客户隐私。
